# Project brochures (PDF)

Each project's **Download Brochure** button links to its OWN PDF here, named by slug:

| File                              | Project          |
|-----------------------------------|------------------|
| `arvind-aqua-city.pdf`            | Arvind Aqua City |
| `arvind-everland.pdf`             | Arvind Everland  |
| `arvind-forreste.pdf`             | Arvind Forreste  |
| `arvind-uplands.pdf`              | Arvind Uplands   |
| `arvind-highgrove.pdf`            | Arvind Highgrove |
| `arvind-alcove.pdf`               | Arvind Alcove    |
| `arvind-smartpark.pdf`            | Arvind SmartPark |

Just drop the PDF in with the exact filename — the button on that project's detail
page starts working automatically.

**Note:** When the site is served over http(s), the Download Brochure button
**auto-hides** for any project whose PDF isn't here yet (so there are no broken
buttons). When you open the HTML files directly (file://) the buttons always show,
because browsers can't check for local files over file://.
